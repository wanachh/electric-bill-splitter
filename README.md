# Electricity Bill Splitter Web App 🔥 (App คำนวณค่าไฟจากความแค้น)

**Inspiration (มาจากไฟแค้นจริงๆ):**
เว็บนี้ไม่ได้สร้างมาเล่นๆ แต่สร้างมาจาก **"ไฟแค้น"** ล้วนๆ! เรื่องมีอยู่ว่าตกลงหารค่าไฟกันดิบดี (พวกเรา 40%, แม่เขา 30%, น้องเขา 25%) แต่พอบิลมาบอก **"ไม่จ่าย เพราะไม่อยู่"** อ้าววว ขึ้นสิครับแต่ด่าไม่ได้เพราะเป็นแม่เขา... ได้! อยากจ่ายเท่าที่อยู่ใช่ไหม? เดี๋ยวกูจัดให้! เลยสั่งเพื่อนรัก(AI)ทำเว็บนี้ขึ้นมา **"อยู่กี่วัน ก็จ่ายไปตามสัดส่วนซะ!"** 

เว็บนี้จะเป็น single page React + Vite + TypeScript รายละเอียดตามด้านล่างเลยจ้า

---

A clean, modern React web application built with Vite to calculate the proportion of the electricity bill each person should pay based on the exact number of days they stayed.

## Features

- **Dynamic Inputs**: Easily add and remove people.
- **Real-Time Calculation**: Results instantly calculate as you type the total price or adjust the days stayed.
- **Modern UI**: Clean and responsive vanilla CSS design system that supports dark mode.

## Prerequisites

- [Node.js](https://nodejs.org/) installed on your machine.

## How to Run Locally

1. **Clone the repository** (if you haven't already):
   ```bash
   cd electric_bill_calc_web
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to the local link provided (usually `http://localhost:5173/`).
